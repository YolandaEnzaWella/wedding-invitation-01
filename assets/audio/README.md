# Musik Latar

Letakkan berkas musik di folder ini dengan nama **`music.mp3`**.

```
assets/audio/music.mp3
```

Halaman akan memutarnya otomatis saat tombol **Buka Undangan** ditekan, dan bisa
dijeda lewat tombol musik mengambang di pojok kanan bawah.

Jika berkas belum ada, undangan tetap berjalan normal — tombol musik hanya
menampilkan pesan bahwa musik belum tersedia.

## Catatan

- Gunakan berkas yang Anda punya haknya (lagu bebas royalti atau izin dari pemiliknya).
- Ukuran wajar: di bawah 3 MB agar undangan tetap ringan dibuka di ponsel.
- Format lain bisa dipakai dengan mengubah `src` pada `<audio id="bgm">` di `index.html`.
